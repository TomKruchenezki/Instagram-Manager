# Instagram Manager

כלי וובי פשוט לניהול וניתוח עוקבים באינסטגרם.  
המערכת מאפשרת להעלות את קובץ הנתונים שמורידים מ־Instagram, לנתח מי עוקב אחרי מי, לזהות חשבונות שלא עוקבים בחזרה, לבנות רשימת הסרת עוקבים ולסווג חשבונות לפי קטגוריות.

> הפרויקט רץ כולו בדפדפן כאתר סטטי — ללא שרת, ללא מסד נתונים וללא התחברות לחשבון Instagram.

---

## מה הפרויקט עושה?

`Instagram Manager` מקבל את קובצי המידע האישיים שהמשתמש מוריד מ־Instagram, בעיקר:

- `followers_1.json` — מי עוקב אחריך.
- `following.json` — אחרי מי אתה עוקב.
- או קובץ ZIP מלא שהורד מ־Instagram ומכיל את הקבצים האלה.

לאחר טעינת הנתונים, האתר מציג Dashboard עם חלוקה נוחה:

- משתמשים שאתה עוקב אחריהם אבל הם לא עוקבים אחריך בחזרה.
- עוקבים הדדיים.
- משתמשים שעוקבים אחריך אבל אתה לא עוקב אחריהם.
- רשימת משתמשים שסימנת להסרת עוקב.
- ניהול קטגוריות וסיווג חשבונות.

- זיהוי חשבונות שלא עוקבים בחזרה.

### רשימת הסרת עוקבים

- הוספת משתמשים לרשימת הסרה ייעודית.
- הסרה מהרשימה.
- ניקוי הרשימה.
- פתיחת פרופיל Instagram של כל משתמש בלחיצה.
- בחירה מרובה והוספה של כמה משתמשים לרשימה בפעולה אחת.

  - חדשות / מדיה
- יצירת קטגוריות מותאמות אישית.

- סיווג ידני של משתמשים.
- סיווג אוטומטי לפי שם משתמש ודפוסים נפוצים.

### חיפוש וסינון

- חיפוש לפי שם משתמש.

## פרטיות

הפרויקט עובד בצד הלקוח בלבד. כלומר, הקבצים נטענים ומנותחים בתוך הדפדפן של המשתמש.

אין בפרויקט:

- Backend.
- Database.
- התחברות לחשבון Instagram.
- שימוש ב־Instagram API.
- שליחת קובצי המשתמש לשרת חיצוני דרך קוד הפרויקט.

שימו לב: הפרויקט טוען את ספריית `JSZip` דרך CDN חיצוני לצורך פתיחת קובצי ZIP. אם רוצים שימוש מלא ללא תלות חיצונית, אפשר להוריד את הספרייה לפרויקט ולטעון אותה מקומית.

---

## טכנולוגיות

- HTML5
- CSS3
- JavaScript Vanilla
- JSZip — לקריאת קובצי ZIP בדפדפן
- LocalStorage — לשמירת העדפת שפה ומצב תצוגה

אין צורך ב־Node.js, npm, build tools או שרת פיתוח.

```text
Instagram-Manager-main/
├── index.html
└── סרטון הדרכה להורדת הקבצי JSON.mp4
```

### `סרטון הדרכה להורדת הקבצי JSON.mp4`

סרטון שמסביר למשתמש איך להוריד את קובצי הנתונים מ־Instagram.

## הרצה מקומית

מכיוון שמדובר באתר סטטי, אפשר פשוט לפתוח את הקובץ בדפדפן:


```bash

```

אפשר גם להריץ שרת סטטי פשוט מתוך תיקיית הפרויקט:

```bash

```

ואז לפתוח בדפדפן:

```text
http://localhost:8000
```

## איך משתמשים באתר?

1. מורידים מ־Instagram את המידע האישי בפורמט JSON.
2. מעלים לאתר את קובץ ה־ZIP שהתקבל, או לחלופין את שני הקבצים:
   - `followers_1.json`
   - `following.json`
3. לאחר הטעינה האתר מציג את רשימות המשתמשים.
4. עוברים בין הלשוניות כדי לראות:
   - מי לא עוקב בחזרה.
   - מי עוקב הדדי.
   - אחרי מי אתה לא עוקב בחזרה.
5. מסמנים משתמשים שרוצים להסיר מהם עוקב ומעבירים אותם לרשימת ההסרה.
6. פותחים את הפרופילים הרלוונטיים ב־Instagram ומבצעים את ההסרה ידנית.

## איך להוריד את הנתונים מ־Instagram?

בתוך האתר קיים מדריך מובנה, אבל באופן כללי:

1. נכנסים ל־Instagram.
2. עוברים לפרופיל האישי.
3. נכנסים לתפריט ההגדרות.
4. נכנסים ל־Accounts Center.
5. בוחרים את אזור המידע וההרשאות.
6. מבקשים להוריד או לייצא את המידע.
7. בוחרים טווח תאריכים: `All time`.
8. בוחרים פורמט: `JSON`.
9. מסמנים רק את `Followers and Following`.
10. יוצרים את הקובץ וממתינים למייל מ־Instagram.
11. מורידים את הקובץ ומעלים אותו לאתר.

## מגבלות ידועות

- האתר לא מבצע הסרת עוקב אוטומטית. הוא רק עוזר לנהל את הרשימה ולפתוח פרופילים.
- הסיווג האוטומטי מבוסס על חוקים ודפוסים בשם המשתמש, ולכן הוא לא תמיד יהיה מדויק.
- רשימות וקטגוריות מנוהלות בזיכרון בזמן השימוש. רענון הדף יאפס את נתוני הניתוח, למעט העדפות שפה ומצב תצוגה.
- קובצי Instagram עשויים להשתנות במבנה שלהם עם הזמן, ולכן ייתכן שיהיה צורך לעדכן את מנגנון הקריאה בעתיד.
